第一章：チーズはどこへ行くか？ 〜1枚の画像が世界を渡る旅（改訂版）〜
主人公のネズミくんは、大好物の「特製エメンタールチーズ」を綺麗に撮影しました。
「この写真を、遠くの街にある『チーズ好き集まれ掲示板（203.0.113.50）』に投稿しよう！」

ネズミくんがスマホの「送信」ボタンをタップした瞬間、技術的にきわめて正確な物語が始まります。

1. 旅立ちの準備と「自ら行う」宛先チェック（パケット・サブネット・CIDR）
ネズミくんのスマホは、大きな画像データを細かく小分けにし、小さな箱パケット（Packet）に詰め込みました。

ここで、ルーターに頼る前に、スマホ自身が頭の中で計算を始めます。

自分のIP: 192.168.1.10

自分たちの家の範囲（サブネット/CIDR）: 192.168.1.0/24（/24 は「192.168.1. までが同じなら同じ家」というルール）

届け先のIP: 203.0.113.50

スマホは判定します。「宛先の頭は 203.0.113. か。僕の家（192.168.1.）とは違うぞ！この相手は家の中にいない。直接手渡しは無理だ！」

家の中にいないと分かったスマホは、迷わず家の中で唯一外の世界を知っている「玄関（デフォルトゲートウェイ：192.168.1.1）」宛にパケットを投げ出しました。

2. 最初の玄関を突破：家からプロバイダの街へ（Default Gateway・LAN）
パケットはWi-Fiの電波（物理層・データリンク層）に乗って、部屋の隅にある家庭用ルーターに届きます。

ルーターはパケットを受け取ると、「よし、うちの家（LAN）の外への配達だな」と確認し、家の外へと繋がる光ファイバーへとパケットを押し出しました。

しかし、家のルーターを出たからといって、いきなり広大な大海原（インターネット/WAN）に出るわけではありません。

3. マトリョーシカのようなネットワーク：街の巨大ローカル網（CGNAT / 2段ルーター）
家のルーターを抜けたパケットが辿り着いたのは、インターネットプロバイダ（ISP）が管理する「街の巨大なローカルネットワーク」でした。

現代の世界では、インターネットの住所（IPv4パブリックIP）が世界中で足りなくなっています。そのため、多くのプロバイダは「大きなマンションの敷地」のように、たくさんの家庭を一度プロバイダ専用の巨大なローカル網の中に集めています。

ネズミくんの家の中: プライベートIP（192.168.1.10）

プロバイダの街の中: プロバイダから配られた別のプライベートIP（10.64.20.5 など）

パケットは、マトリョーシカのように「ローカル網の中の、さらに大きなローカル網」をスイスイと通過していきます。

4. 本物のパスポートを手に入れる：国境の関門（NAPT / NAT と パブリックIP）
プロバイダのローカル網の最果てに、目を見張るほど巨大なルーター（CGNAT：キャリアグレードNAT）がそびえ立っていました。ここが、本物のインターネット（WAN）との国境です。

「ここから先は、世界でひとつだけの『本物の住所』がないと通行できないぞ」

プロバイダの巨大ルーターは、ネズミくんのパケットに刻まれた内線番号（10.64.20.5）を削り取り、プロバイダが所有する世界で唯一のパブリックIPアドレス（198.51.100.7）と、識別用のポート番号をラベルにペタッと貼り直しました（NAPT変換）。

「これでよし。世界中どこからでも、君の元へ返事が戻ってこられるようになった！」

5. 大海原を越えて：世界へ羽ばたくチーズ
本物のパスポート（パブリックIP）を手に入れたパケットは、ついに遮るもののないインターネット（WAN）の大海原へと飛び出しました。

世界中のルーターたちが「203.0.113.50 はあっちだ！」とバケツリレー（ダイナミックルーティング）でバトンを繋ぎ、パケットは海底ケーブルを越えて、目的地の『チーズ好き集まれ掲示板』のサーバーへ無事に到着しました。

バラバラに届いたパケットたちがサーバー上で組み立てられ、掲示板には見事な「特製エメンタールチーズ」の画像が投稿されたのです。
